# PPG 别名映射表 (Alias Mapping Table)

> 本表是"交叉引用清零"工作(Phase 1-5)的核心产物,记录每个验收ID与其TB场景名、RTL标签位置的真实对应关系。
> 之前这层关系只存在于矩阵文字和memory散文里,从未显式建表。
>
> schema与标签约定定义于memory `project-ppg-dual-anchor-tagging-convention.md`。
>
> 本表由对话A1(Phase 1a/1b)创建并首批填充,后续对话(A2/Phase 2-5)继续核对与扩充。
> Phase 4会把本表(或其快照)折叠进 `PPG_CONTRACT_CLOSURE_MATRIX.md` 新增的 §13。
>
> **本表是人工/半自动填写的当前快照,不是脚本自动生成物**——Phase 2的核对脚本会读取本表并与RTL实际标签、矩阵文字做三向比对,发现的不一致分三类处理,见Phase 2脚本设计,不在本表内解决。

## 字段说明

| 字段 | 含义 |
| --- | --- |
| 验收ID | 如 `TOP-06`、`K01`、`G-FP-01-D01-04`、`JNT-03` |
| 对应TB场景名 | 现有TB的`$display`场景名/PASS标记,例如`FIR_TAIL_ISOLATION_TB_PASS`的`GROUP4_TAIL_BOUNDED` |
| 对应RTL标签位置(文件:行) | 与RTL端`@satisfies`标签位置一致的真实`文件:行`;多ID共享同一锚点时该字段值相同、每ID各占一行 |
| 出处 | matrix行号或memory文件名,标明证据链来源 |

行内没有真实映射时如实填"无映射",不得留空或编造。
